# 五分钟本地演示

演示适用于已安装并启动的路序原型。入口为 <http://127.0.0.1:8080/>，仅在运行服务的电脑上访问，不是公网演示地址。地点查询、道路规划和地图瓦片需要联网。

## 1. 登录与录入

注册一个新账号并登录。用户名 3～40 位、密码 10～128 位。创建配送任务，打开“配送数据”。

按 [杭州公开道路体验数据](可录入体验数据.md) 手动填写配送站、2 笔订单及 2 辆车辆。每笔订单、每辆车辆填写后，分别点击添加按钮。

这些业务参数是人工设定的体验输入，道路来自公开真实服务，不代表真实企业运营订单。日期和收货窗口必须保持一致；原示例日期可按演示当天同步调整。

## 2. 加载道路与规划

点击“加载真实道路”，等待成功，再生成方案。地图应展示沿道路的路线、收货点和返站路径。

已保存的开发验收案例完成 2/2 单，使用 1 辆车，道路里程约 4.821 km，输入参数估算费用 35.79 元。公共道路更新或输入修改可能使结果变化；以当前计算和约束检查为准。

## 3. 体验 AI 与基准对比

在对话框发送“分析订单风险”“解释当前方案”，查看基于录入数据和计算结果的说明。

点击“对比基准”，比较同一数据版本上的完成订单数、里程、费用和出车数。体验案例不保证优化方案在所有指标上优于基准，也不能用它证明企业实际成本降低。

## 4. 播放路线预演

点击播放，确认车辆随进度沿路线移动；依次尝试暂停、修改速度、拖动进度和重播。它是计划路线预演，不是真实车辆定位。

拖动桌面分隔线调整栏宽；点击地图“全国”返回全国视野，再点击“查看全部配送点”回到任务范围。

## 5. 故障重调度（可选）

发送“V01 故障，请重新调度”，先查看停用建议，再点击应用。保留 V02 可用，然后重新生成方案，检查原订单是否转由可用车辆配送。

如果两辆车都不可用或参数不满足约束，界面应给出失败或未分配说明，不能播放空方案。

## 结束

关闭网页不会停止服务。在运行服务的终端按 Ctrl+C 停止；已保存数据留在本机运行数据库中，默认不纳入参赛压缩包或源码仓库。
